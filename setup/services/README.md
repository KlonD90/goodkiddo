# Setup Services

Guide to generated service files and service checks.

## Contains

- `service-defs.ts`
- `service-renderers.ts`
- `service-installers.ts`
- `verify-services.ts`

## Troubleshoot Here

- bad launchd/systemd/nohup output
- service install failures
- wrong service topology
- verify status mismatches

Keep user-facing setup flow in `../steps/`.
